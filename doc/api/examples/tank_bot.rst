タンクボット
================

このサンプルプロジェクトでは、
:class:`GyroSensor <pybricks.ev3devices.GyroSensor>`
をタンクボットで使って正確に旋回する方法を紹介します。
押すEV3 Brickのボタンによって、ロボットは三角形・正方形・五角形・六角形に走行します。

`こちら <here_>`_ から拡張セットモデルの組み立て説明書をすべて確認できます。また、
