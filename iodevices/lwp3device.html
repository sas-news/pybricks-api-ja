LEGO Wireless Protocol v3デバイス

class LWP3Device(hub_kind, name=None, timeout=10000, pair=False, num_notifications=8, connect=True)

LEGO Wireless Protocol v3 を使用して、公式のLEGOファームウェアを 実行しているハブに接続します。

Parameters:

  • hub_kind (int) – 接続するハブの hub type identifier 。

  • name (str) – 接続するハブの名前。 None を指定すると、任意のハブに 接続します。

  • timeout (int) – 例外が発生するまで接続を待機する時間（ミリ秒）。

  • pair (bool) – セキュアな接続のためにペアリングを試みるかどうか。 一部の新しいハブでは必須です。

  • num_notifications (int) – 古いメッセージを破棄するまでに保持する リモートハブからの受信メッセージ数。

  • connect (bool) – 接続をスキップする場合は False を選択します。 connect() を後で呼び出して接続できます。

Changed in version 3.6: pair パラメータを追加しました。

Changed in version 3.7: num_notifications パラメータを追加しました。

await connect()

デバイスに接続します。切断した場合、または connect=False で 初期化した場合にのみ必要です。

Raises:

OSError – 接続の試行が失敗したかタイムアウトした場合。

name(name)
name() → str

デバイスのBluetooth名を設定または取得します。

Parameters:

name (str) – デバイスの新しいBluetooth名。名前が指定されない場合、 このメソッドは現在の名前を返します。

Raises:

OSError – デバイスが接続されていない場合。

await write(buf)

リモートハブにメッセージを送信します。

Parameters:

buf (bytes) – 送信する生のバイナリメッセージ。最大20バイト。

Raises:

  • ValueError – メッセージが20バイトを超える場合。

  • OSError – デバイスが接続されていない、または書き込みに失敗した 場合。

read() → bytes | None

リモートハブから受信した最も古いバッファ内のメッセージを取得します。

バッファ内のすべてのメッセージがすでに読み取られている場合は、 None を返します。

Returns:

最も古い生のバイナリメッセージ。メッセージがない場合は None。

Changed in version 3.7: 新しいメッセージが1つ受信されるまでブロックする代わりに、 バッファ内の複数のメッセージを読み取れるようになりました。

await disconnect()

デバイスを切断します。

Raises:

OSError – 切断に失敗した場合。
