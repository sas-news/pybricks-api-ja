# EV3画像の日本語化作業ルール（このファイルはpush前に削除すること）

対象: `ev3/_images/*_label.png`（手順見出しバナー 21枚）
除外: その他のPNG/JPG（センサー・部品の写真、UIスクリーンショット本体、アイコン等）は触らない。
例外で対象に含めてよいのは `datalog_graph.png` のみ（Excel画面のラベル。難しければスキップでOK、その旨を報告）。

## 各画像の処理方法（PIL使用）

1. 画像を read ツールで開き、上部バナーにある英語の手順テキスト（丸数字＋見出し）を読み取る。
2. 丸数字（①②③…）と、画像内のスクリーンショット/写真部分は絶対に変更しない。
3. 白背景のテキスト領域だけを消す: 該当範囲を背景色（ほぼ白 #FFFFFF〜#F8F8F8）で矩形塗りつぶし。
   - 範囲は「丸数字の右」から「バナー右端」まで。バナー高さは画像先頭から約40〜60px（実際に開いて確認）。
4. 同じ位置に日本語テキストを描画:
   - フォント: `/home/ubuntu/.local/share/fonts/NotoSansCJKjp-Regular.otf`
   - サイズ: 元の英語と同等（画像幅1080pxで約28-36pxが目安。実際に見て調整）
   - 色: 黒〜濃灰（元の文字色を拾う）
   - 縦位置は元テキストのベースラインに揃える
5. 翻訳方針（丁寧、バランス重視）:
   - 手順を自然な日本語で。例: "Scan for devices" → 「デバイスをスキャン」、"Select your EV3" → 「使いたいEV3を選択」、"Download the installer" → 「インストーラーをダウンロード」
   - 製品名・固有名詞（EV3, Bluetooth, VS Code, Etcher, microSD 等）は英語のまま。
   - 短く簡潔に。目安は12文字以内。丸数字は描き直さず残す。
6. 上書き保存（同じファイル名・同じPNGフォーマット）。最適化ツールは使わない。
7. 保存後、自分で画像を開き直して確認: 日本語が読めるか、元の英語が残っていないか、バナー以外が変わっていないか。

## コミット

`ev3/_images: <対象画像の簡単な説明> 日本語化` 形式でまとめて1コミット。
このファイル（ev3/TRANSLATE-img.md）は作業完了後に削除してからpushすること。
