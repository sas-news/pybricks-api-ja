例外とエラー

このセクションでは、利用可能なすべての例外をアルファベット順に列挙します。

class ArithmeticError

さまざまな算術エラーに対して送出される組み込み例外の基底クラス。

class AssertionError

assert文が失敗したときに送出されます。

class AttributeError

属性の参照または代入が失敗したときに送出されます。

class BaseException

すべての組み込み例外の基底クラス。

ユーザー定義クラスから直接継承することは意図されていません （その場合は Exception を使用してください）。

class EOFError

input() 関数がデータを読み取る前にファイル終端（EOF）に 達したときに送出されます。

class Exception

すべての組み込み例外はこのクラスから派生しています。

すべてのユーザー定義例外もこのクラスから派生させる必要があります。

class GeneratorExit

ジェネレーターまたはコルーチンが閉じられたときに送出されます。

class ImportError

import 文がモジュールを読み込めなかったときに送出されます。

class IndentationError

不正なインデントに関連する構文エラーの基底クラス。

class IndexError

シーケンスの添字が範囲外のときに送出されます。

class KeyboardInterrupt

ユーザーが割り込みキー（通常は Ctrl C ）を押したときに 送出されます。

class KeyError

マッピング（辞書）のキーが既存のキーの中に見つからないときに送出されます。

class LookupError

マッピングまたはシーケンスで使用するキーまたはインデックスが 無効な場合に送出される例外の基底クラス。

class MemoryError

操作がメモリ不足になったときに送出されます。

class NameError

ローカル名またはグローバル名が見つからないときに送出されます。

class NotImplementedError

ユーザー定義の基底クラスでは、派生クラスにメソッドのオーバーライドを 要求する抽象メソッド、または実際の実装がまだ追加される必要があることを 示す開発中のクラスで、この例外を送出する必要があります。

class OSError

この例外は、ハブ上で動作するオペレーティングシステムである ファームウェアによって送出されます。 例 として、ポートAにモーターが 接続されていないときに Motor(Port.A) を呼び出すと OSError が送出されます。

errno: int

発生した OSError の種類を指定します。種類は uerrno モジュールに列挙されています。

class OverflowError

算術演算の結果が表現できないほど大きいときに送出されます。

class RuntimeError

他のどのカテゴリーにも当てはまらないエラーが検出されたときに送出されます。

関連する値は、何が具体的に問題だったかを示す文字列です。

class StopIteration

組み込み関数 next() とイテレーターの __next__() メソッドが、 イテレーターがこれ以上要素を生成しないことを示すために送出されます。

ジェネレーター関数は、これを直接送出する代わりにreturnすべきです。

class SyntaxError

パーサーが構文エラーに遭遇したときに送出されます。

class SystemExit

ハブまたはPybricks Codeアプリの停止ボタンを押したときに送出されます。

class TypeError

操作または関数が不適切な型のオブジェクトに適用されたときに送出されます。

class ValueError

操作または関数が、正しい型だが不適切な値の引数を受け取ったときに 送出されます。これは、 IndexError のようなより正確な例外で 状況が説明できない場合に使用されます。

class ZeroDivisionError

除算または剰余演算の第2引数が0のときに送出されます。

使用例

REPLターミナルでのデバッグ

from pybricks.parameters import Port
from pybricks.pupdevices import Motor
from pybricks.tools import wait

# Initialize the motor.
test_motor = Motor(Port.A)

# Start moving at 500 deg/s.
test_motor.run(500)

# If you click on the terminal window and press CTRL+C,
# you can continue debugging in this terminal.
wait(5000)

# You can also do this to exit the script and enter the
# terminal. Variables in the global scope are still available.
raise KeyboardInterrupt

# For example, you can copy the following line to the terminal
# to get the angle, because test_motor is still available.
test_motor.angle()

停止ボタンを押したときにコードを実行する

from pybricks.tools import wait

print("Started!")

try:
    # Run your script here as you normally would. In this
    # example we just wait forever and do nothing.
    while True:
        wait(1000)

except SystemExit:
    # This code will run when you press the stop button.
    # This can be useful to "clean up", such as to move
    # the motors back to their starting positions.
    print("You pressed the stop button!")

OSError を使ったデバイスの検出

from pybricks.parameters import Port
from pybricks.pupdevices import Motor
from uerrno import ENODEV

try:
    # Try to initialize a motor.
    my_motor = Motor(Port.A)

    # If all goes well, you'll see this message.
    print("Detected a motor.")
except OSError as ex:
    # If an OSError was raised, we can check what
    # kind of error this was, like ENODEV.
    if ex.errno == ENODEV:
        # ENODEV is short for "Error, no device."
        print("There is no motor this port.")
    else:
        print("Another error occurred.")
