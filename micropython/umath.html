umath – 数学関数

このMicroPythonモジュールは、Pythonの math module に似ています。

何もインポートせずに使用できる built-in math functions も参照してください。

丸めと符号

ceil(x) → int

切り上げます。

Parameters:

x (float) – 丸める対象の値。

Returns:

正の無限大方向に丸めた値。

floor(x) → int

切り捨てます。

Parameters:

x (float) – 丸める対象の値。

Returns:

負の無限大方向に丸めた値。

trunc(x) → int

小数を切り捨てて値の整数部分を取得します。

これは 0 方向への丸めと同じです。

Parameters:

x (float) – 切り捨てる対象の値。

Returns:

値の整数部分。

fmod(x, y) → float

x / y の剰余を取得します。

modf() と混同しないでください。

Parameters:

  • x (float) – 分子。

  • y (float) – 分母。

Returns:

除算後の剰余。

fabs(x) → float

絶対値を取得します。

Parameters:

x (float) – 値。

Returns:

x の絶対値。

copysign(x, y) → float

y の符号を持つ x を取得します。

Parameters:

  • x (float) – 戻り値の大きさを決定します。

  • y (float) – 戻り値の符号を決定します。

Returns:

y の符号を持つ x。

べき乗と対数

e = 2.718282

数学定数 e。

exp(x) → float

e の x 乗を取得します。

Parameters:

x (float) – 指数。

Returns:

e の x 乗。

pow(x, y) → float

x の y 乗を取得します。

Parameters:

  • x (float) – 底。

  • y (float) – 指数。

Returns:

x の y 乗。

log(x) → float

自然対数を取得します。

Parameters:

x (float) – 値。

Returns:

x の自然対数。

sqrt(x) → float

平方根を取得します。

Parameters:

x (float) – 値 x。

Returns:

x の平方根。

三角関数

pi = 3.141593

数学定数 π。

degrees(x) → float

角度をラジアンから度に変換します。

Parameters:

x (float) – ラジアン単位の角度。

Returns:

度単位の角度。

radians(x) → float

角度を度からラジアンに変換します。

Parameters:

x (float) – 度単位の角度。

Returns:

ラジアン単位の角度。

sin(x) → float

角度の正弦を取得します。

Parameters:

x (float) – ラジアン単位の角度。

Returns:

x の正弦。

asin(x) → float

逆正弦演算を適用します。

Parameters:

x (float) – 対辺 / 斜辺。

Returns:

x の逆正弦（ラジアン単位）。

cos(x) → float

角度の余弦を取得します。

Parameters:

x (float) – ラジアン単位の角度。

Returns:

x の余弦。

acos(x) → float

逆余弦演算を適用します。

Parameters:

x (float) – 隣辺 / 斜辺。

Returns:

x の逆余弦（ラジアン単位）。

tan(x) → float

角度の正接を取得します。

Parameters:

x (float) – ラジアン単位の角度。

Returns:

x の正接。

atan(x) → float

逆正接演算を適用します。

Parameters:

x (float) – 対辺 / 隣辺。

Returns:

x の逆正接（ラジアン単位）。

atan2(b, a) → float

b / a に対して逆正接演算を適用し、b と a の符号を考慮して 期待される角度を生成します。

Parameters:

  • b (float) – 三角形の対辺。

  • a (float) – 三角形の隣辺。

Returns:

b / a の逆正接（ラジアン単位）。

その他の数学関数

isfinite(x) → bool

値が有限かどうかを確認します。

Parameters:

x (float) – 確認する値。

Returns:

x が有限なら True、そうでなければ False。

isinfinite(x) → bool

値が無限かどうかを確認します。

Parameters:

x (float) – 確認する値。

Returns:

x が無限なら True、そうでなければ False。

isnan(x) → bool

値が非数かどうかを確認します。

Parameters:

x (float) – 確認する値。

Returns:

x が非数なら True、そうでなければ False。

modf(x) → tuple[float, float]

x の小数部分と整数部分を取得します。いずれも x と同じ符号 になります。

fmod() と混同しないでください。

Parameters:

x (float) – 分解する値。

Returns:

小数部分と整数部分のタプル。

frexp(x) → tuple[float, float]

値 x を x == m * (2 ** p) となるようなタプル (m, p) に分解します。

Parameters:

x (float) – 分解する値。

Returns:

m と p のタプル。

ldexp(m, p) → float

m * (2 ** p) を計算します。

Parameters:

  • m (float) – 値。

  • p (float) – 指数。

Returns:

m * (2 ** p) の結果。
